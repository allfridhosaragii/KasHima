# Deploy KasHima ke GitHub Pages

1. Publikasikan repository ini di https://github.com/allfridhosaragii/KasHima.
2. Buka Settings > Pages dan pilih Source: GitHub Actions jika perlu.
3. Workflow `deploy-pages.yml` akan build dan deploy statis otomatis saat push `main`.
4. URL yang diharapkan setelah deployment berhasil: https://allfridhosaragii.github.io/KasHima/.
5. Uji ulang Chrome Android dan Safari iPhone. Untuk masalah cache, refresh halaman dan hapus shortcut home screen demo lama.

Website adalah demo frontend. GitHub Pages tidak menjalankan backend, autentikasi atau proses QRIS sungguhan.
