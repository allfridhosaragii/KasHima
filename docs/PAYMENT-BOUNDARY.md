# Pembayaran KasHima — Batasan Demo

- QR pada demo tidak mewakili QRIS merchant yang sah.
- Data pembayaran, ledger, history dan approval pada demo disimpan di localStorage pengguna.
- Tanpa sumber informasi transaksi resmi/diizinkan, aplikasi tidak bisa memastikan transfer sukses otomatis.
- Screenshot, klik tombol, pemindaian QR atau kecocokan nominal tidak membuktikan dana diterima.
- Backend produksi harus mengharuskan transaksi terverifikasi, deduplikasi dan pencatatan atomik sebelum halaman sukses final.
- Jangan memasukkan data atau uang asli pada demo GitHub Pages ini.
